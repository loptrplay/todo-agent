# 小明智能体 · 待办清单编程题

小明是一个中文待办智能体。React 和 TypeScript 提供聊天与任务面板，Node.js 和 Express 提供聊天与任务 API。明确指令优先由本地规则处理，复杂表达交给 DeepSeek。两种路径都由服务端校验参数、通过同一个 `TaskStore` 操作本地 JSON，并核对写入后再生成回执。

## 基础要求

请让用户能通过聊天完成创建、查看、标记完成和删除这四种操作。任务应保存到本地，刷新页面或重启服务后仍可查询。

可以从 [server/agent.ts](server/agent.ts) 开始，在这里接收对话历史并返回本轮回复。

任务接口的路径、字段和返回值见 [OpenAPI 说明](server/openapi.yaml)。

下面是一段验收对话。

| 用户对小明说     | 预期结果                                   |
| ---------------- | ------------------------------------------ |
| 帮我记一下买牛奶 | 新增待办「买牛奶」                         |
| 再记一条取快递   | 清单里多了一条「取快递」                   |
| 我有哪些任务？   | 列出两条任务，并能看出各自的完成状态       |
| 牛奶买好了       | 把「买牛奶」标记为已完成，「取快递」仍待办 |
| 取快递这条删掉吧 | 删除「取快递」                             |
| 再给我看看清单   | 只剩已完成的「买牛奶」                     |

## V3 功能

- 支持「明天下午三点开会」「周五交报告」等截止日期表达。日期保留 `YYYY-MM-DD`，带时刻的截止日期保存为 UTC。聊天按浏览器时区判断今天、逾期和未来到期任务。
- 支持一级子任务。例如先创建「准备法国旅行」，再请小明添加「订机票」和「预订酒店」。子任务可独立完成和删除，主任务仍有子任务时会阻止删除。
- 可通过「把准备报告设为高优先级」或「买牛奶的工作量设为小」更新任务属性。
- 任务卡片显示任务状态、截止日期、优先级、工作量和子任务进度。面板支持关键词搜索、优先级和工作量筛选、截止日期排序以及全清单的总数、完成数、未完成数和完成率。窄屏可在对话和清单间切换，清单支持手动刷新，也会在聊天请求结束后刷新。
- 按序号操作时使用最近一次展示清单对应的任务 ID。「刚才添加的任务」和「刚才完成的任务」使用当前对话中已核对的回执定位。否定指令会保留清单，含义不明确的取消请求会先确认意图。
- `server/task-intent.ts` 负责识别常见的本地指令，`server/agent.ts` 统一处理本地操作与模型工具调用。模型连接、认证、余额和限流异常都有对应提示。

## 快速开始

安装 Node.js 24.12 或更高版本，在项目根目录运行以下命令。

```sh
npm ci
npm run dev
```

打开 <http://127.0.0.1:3000>。接入模型时，把 `.env.example` 复制为本地 `.env`，填写自己的 `DEEPSEEK_API_KEY`，再重启服务。`DEEPSEEK_MODEL` 可选。未配置密钥或模型不可用时，明确的新增、查询、完成、删除和部分属性修改指令仍由本地规则处理。详细步骤见[本地开发指南](GETTING_STARTED.md)。

任务数据存放在 `data/tasks.json`，脚本运行目录为项目根目录。V1 JSON 可直接使用，已有额外字段保留。任务在关闭页面或重启服务后仍存在，聊天历史随页面刷新清空。

50 项测试全部通过。测试使用临时 JSON 和模拟模型。原题六步在无密钥规则模式与模拟 DeepSeek 模式下分别连续执行，每一步都检查实际数据。入口测试在临时目录启动后端，验证聊天和 REST API 共用同一份清单。实际 DeepSeek 的语言理解仍需使用自己的 API Key 验证。检查格式时可运行 `npx --no-install oxfmt --check <文件路径>` 指定修改文件。
